![Transição para o Moodle Marketplace](/images/moodle_marketplace_transition.png)

Uma grande mudança está acontecendo no ecossistema do Moodle. O tradicional **Diretório de Plugins**, que durante 15 anos ajudou a comunidade a compartilhar, descobrir e melhorar ferramentas para a plataforma, está se despedindo para dar lugar a uma plataforma mais moderna: o **Moodle Marketplace**.

A partir de hoje, o Diretório de Plugins entrou em modo "somente leitura" (read-only) para iniciar o processo de migração. A previsão oficial é que o novo Moodle Marketplace seja lançado na próxima segunda-feira, **20 de julho de 2026**.

## O que muda para os usuários neste momento?

Durante este período de transição, você não ficará sem acesso às ferramentas. Ainda é possível navegar pelo diretório antigo e realizar o download dos plugins normalmente. 

No entanto, as seguintes ações estão suspensas até o lançamento do novo marketplace:
* Não é mais possível enviar novos plugins.
* Não é permitido fazer alterações ou atualizações nas listagens de plugins existentes.

## E para os desenvolvedores e provedores de plugins?

Todas as submissões de plugins serão movidas para a nova plataforma assim que ela for lançada. Se você é um desenvolvedor ou provedor de plugins e quer se preparar para as mudanças, a [documentação para provedores do Moodle Marketplace](https://moodle.atlassian.net/wiki/external/YTI4MmY4MWU2MDQyNDk5MTllZWY4YTBiNjA5ZDRjNWY) continua disponível para consulta.

## O fim de um ciclo de 15 anos

O Diretório de Plugins foi uma peça fundamental para o sucesso e a flexibilidade do Moodle ao longo de uma década e meia, abrigando milhares de soluções criadas por desenvolvedores do mundo todo. Essa transição para o Moodle Marketplace promete trazer uma experiência mais fluida, unificada e aprimorada tanto para quem busca expandir seu ambiente virtual de aprendizagem quanto para quem desenvolve essas soluções.

Fique de olho! Na próxima segunda-feira (20), um novo capítulo se inicia para a comunidade Moodle.
